## Spacing Scale

All values reference existing tokens from `frontend/src/index.css`. No new spacing tokens needed for Phase 2.

| Token | CSS Var | Value | Usage in Phase 2 |
|-------|---------|-------|-------------------|
| xs | `--space-xs` | 4px (0.25rem) | Icon gaps, chip X button padding, priority dot margin |
| sm | `--space-sm` | 8px (0.5rem) | Chip internal padding, badge padding, row cell padding (compact) |
| md | `--space-md` | 16px (1rem) | Table cell padding (comfortable), drawer section gap, filter row padding |
| lg | `--space-lg` | 24px (1.5rem) | Drawer content padding, section headers, card padding |
| xl | `--space-xl` | 32px (2rem) | Drawer header area, empty state vertical padding |
| 2xl | `--space-2xl` | 48px (3rem) | Empty state full padding block |

Exceptions:
- **Touch targets (RESP-03):** All interactive elements minimum 44px height/width. This overrides compact density row height. Apply `min-height: 44px` on `<tr>` click targets and all toolbar buttons on mobile.
- **Row density heights (VIEW-08):** `--row-height-compact: 32px`, `--row-height-comfortable: 40px`, `--row-height-spacious: 52px` — add these three tokens to `index.css`. These are TanStack Virtual fixed heights and intentionally fall outside the spacing scale.
- **Detail drawer width:** Fixed 400px on desktop — not a spacing token, a layout constant. Add `--drawer-width: 400px` to `index.css`.

## Typography

All values reference existing tokens from `index.css`. Phase 2 uses exactly 4 type roles and exactly 2 font weights.

| Role | CSS Var | Size | Weight | Line Height | Usage |
|------|---------|------|--------|-------------|-------|
| Body | `--font-size-base` | 14px (0.875rem) | 400 (`--font-weight-normal`) | 1.5 (`--leading-normal`) | Table cell text, card summary, drawer body copy |
| Label | `--font-size-sm` | 12px (0.75rem) | 600 (`--font-weight-semibold`) | 1.25 (`--leading-tight`) | Filter chips, badges, table column headers, density toggle labels |
| Heading | `--font-size-md` | 16px (1rem) | 600 (`--font-weight-semibold`) | 1.3 | Drawer section headings, priority group section headers |
| Display | `--font-size-xl` | 24px (1.5rem) | 600 (`--font-weight-semibold`) | 1.25 (`--leading-tight`) | Drawer communication title / comm number |

Weights declared: `--font-weight-normal` (400) and `--font-weight-semibold` (600) only. `--font-weight-medium` (500) is not used in Phase 2.

Note: Table column headers use Label role + `text-transform: uppercase` + `letter-spacing: 0.05em` — matching the existing `th` rule in `index.css`.

## Color

All values reference existing tokens from `index.css`. No new color tokens needed except `--color-highlight` (FILT-03).

| Role | CSS Var | Value | Usage |
|------|---------|-------|-------|
| Dominant (60%) | `--bg-base` | hsl(225, 25%, 8%) | Table background, card grid background, drawer backdrop tint |
| Secondary (30%) | `--bg-surface` / `--bg-elevated` | hsl(225, 22%, 11%) / hsl(225, 20%, 14%) | Table header sticky row, card surfaces, drawer panel background, filter chip row background |
| Accent (10%) | `--color-primary` | hsl(210, 100%, 56%) | **Reserved for:** active sort column indicator arrow, focused search input border + glow, view toggle active state, "Clear all" link color |
| Destructive | `--color-danger` | hsl(0, 84%, 60%) | Chip X dismiss button hover state only (no destructive actions in this phase) |

Accent reserved for (explicit list):
1. Active sort column header arrow/indicator
2. Search input `:focus` border + glow ring
3. View toggle (table/card) active/selected state
4. "Clear all" filter action text link

Priority colors (from `types.ts` — already established, not new):
- High: `hsl(0, 75%, 55%)` — priority dot + section header in group mode
- Medium: `hsl(45, 90%, 50%)` — priority dot + section header
- Low: `hsl(145, 60%, 45%)` — priority dot + section header

Search highlight color — **new token to add to `index.css`:**
- `--color-highlight: hsl(45, 100%, 50%)` — amber `<mark>` background for search match highlighting (FILT-03)
- Mark text color: `--text-primary` to maintain readability on amber background

Type badge colors come from `COMM_TYPE_COLORS` in `types.ts` — existing, use as-is.

## Focal Point

**Primary Communications View focal point:** The communications list (table or card grid) is the primary focal point. It occupies the dominant surface area. The vehicle selector/context header anchors the top of the view with reduced visual weight (`--text-secondary`, `--font-size-sm`). The filter toolbar sits between them as a secondary affordance zone. On first load with data, the eye should land on the first row/card — no competing hero elements.

On mobile, the full-screen card grid is the sole focal point with the filter chip row collapsed by default.

## Interaction Contracts

### Table (VIEW-01–03)

| Interaction | Behavior |
|-------------|----------|
| Row click | Opens detail drawer; row gets `background: var(--bg-active)` selected state |
| Column header click | Cycles sort: unsorted → asc → desc → unsorted. Shows `↑` / `↓` arrow in accent color |
| Active sort column | Header background: `var(--bg-elevated)`, arrow in `var(--color-primary)` |
| Row hover | `background: var(--bg-hover)` — matches existing `tr:hover td` rule |
| Density toggle | Sets `--row-height` CSS custom property on table container; triggers TanStack Virtual recalculation |

### Card View (VIEW-04)

| Interaction | Behavior |
|-------------|----------|
| Card click | Opens detail drawer (same behavior as table row click) |
| Card hover | `border-color: var(--border-default)`, `box-shadow: var(--shadow-md)` — matches existing `.card:hover` |

### View Toggle (VIEW-05, VIEW-06)

| Interaction | Behavior |
|-------------|----------|
| Toggle click | Switches between table and card; persisted to `localStorage` key `comms-view-mode` |
| Active state | Active button: `background: var(--color-primary)`, `color: white` |
| Inactive state | `background: var(--bg-elevated)`, `color: var(--text-secondary)` |
| Mobile (<768px) | Toggle hidden; forced card-only mode |

### Density Toggle (VIEW-08)

| Interaction | Behavior |
|-------------|----------|
| Toggle | Three-option segmented control: Compact / Comfortable / Spacious |
| Persisted | `localStorage` key `comms-density`, default `comfortable` |
| Active state | Same pattern as view toggle active state |
| Scope | Table view only — density control hidden when card view active |
| Row heights | Compact: 32px, Comfortable: 40px, Spacious: 52px (via `--row-height` CSS custom property) |

### Detail Drawer (VIEW-07)

| Interaction | Behavior |
|-------------|----------|
| Open | Slide in from right — `transform: translateX(100%)` → `translateX(0)` in `var(--transition-default)` (250ms) |
| Close (X button) | Slide out right; `selectedCommId` set to null |
| Close (Escape key) | Same as X button |
| Close (backdrop click) | Semi-transparent backdrop `hsla(225, 25%, 4%, 0.6)`; click triggers close |
| Desktop width | 400px fixed (`--drawer-width`) |
| Mobile (<768px) | Full-screen overlay; "Back to list" button in top-left replaces X button |
| Z-index | `var(--z-overlay)` = 20 |
| Content | Flat — no tabs, no accordions. Sections: header (comm #, type badge), summary, details summary, products, documents, keywords |

### Filter Chips (FILT-01)

| Interaction | Behavior |
|-------------|----------|
| Chip X click | Removes that specific filter from state |
| "Clear all" click | Removes all active filters simultaneously |
| Zero filters active | Chip row hidden entirely (zero-state = clean toolbar) |
| Chip appearance | `background: var(--bg-elevated)`, `border: 1px solid var(--border-default)`, `border-radius: var(--radius-full)`, height 28px |
| Chip X hover | X icon color: `var(--color-danger)` |
| Chip X aria-label | `aria-label="Remove [filter name] filter"` — e.g. `aria-label="Remove TSB filter"` or `aria-label="Remove search filter"` |

### Priority Group Toggle (FILT-04)

| Interaction | Behavior |
|-------------|----------|
| "Group by priority" button | Toggle in toolbar; active state uses accent color pattern |
| Default state | High section expanded, Medium + Low collapsed |
| Section header click | Collapse/expand that priority section |
| Section count | Shows `(n)` count after priority label in muted color |

### Responsive (RESP-01–03)

| Breakpoint | Behavior |
|------------|----------|
| ≥768px | Table or card view per user toggle; sidebar visible |
| <768px | Card view forced; view toggle hidden; sidebar hamburger overlay |
| All breakpoints | Touch targets minimum 44×44px (buttons, chips, table rows, drawer close) |
