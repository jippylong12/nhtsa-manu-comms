Create `frontend/src/features/communications/components/CommunicationTable.tsx`:

The table component uses TanStack Table for state management and TanStack Virtual for row virtualization. It renders a standard HTML `<table>` element with CSS-controlled styling.

**Column definitions (in order):**
1. **Type** — `communicationType` as a colored badge. Background: `color-mix(in srgb, var(--type-color) 15%, transparent)`. Text color: the type color. Width: 64px.
2. **Priority** — Derived via `getCommPriority(comm.communicationType)`. Renders as a 10px colored dot using `PRIORITY_COLORS`. Width: 40px.
3. **Date** — `communicationDate` formatted with `format(new Date(date), 'MMM d, yyyy')` from date-fns. Width: 100px. Default sort column (descending).
4. **Summary** — `summary` truncated via CSS `text-overflow: ellipsis; white-space: nowrap`. Flex: 1 (takes remaining space). Uses `HighlightText` when searchTerm is active.
5. **Comm #** — `communicationNumber` in monospace font. Width: 120px. Uses `HighlightText` when searchTerm is active.
6. **Docs** — `associatedDocuments.length` with a FileText icon. Width: 56px.
7. **Keywords** — `matchedKeywords` as small badges (show first 2, +N more). Width: 120px.

**Props interface:**
```typescript
interface CommunicationTableProps {
  communications: Communication[];
  isLoading?: boolean;
  searchTerm?: string;
  density: Density;
  onRowClick: (comm: Communication) => void;
  selectedCommId?: number | null;
}
```

**TanStack Table setup:**
- `useReactTable` with `getCoreRowModel()`, `getSortedRowModel()`, `getFilteredRowModel()`
- Initial sort state: `[{ id: 'date', desc: true }]` (newest first)
- Multi-sort disabled (single column sort only)
- Column definitions use `columnHelper.accessor(...)` for type-safe column defs

**TanStack Virtual setup:**
- `useVirtualizer` with `count: table.getRowModel().rows.length`
- `getScrollElement: () => tableContainerRef.current`
- `estimateSize: () => DENSITY_ROW_HEIGHTS[density]`
- `overscan: 5`

**Rendering structure:**
```
<div ref={tableContainerRef} className={styles.container} style={{ height: '100%', overflow: 'auto' }}>
  <table className={styles.table}>
    <thead className={styles.thead}>
      {headerGroups → <tr> → <th> with sort indicator (▲/▼/⬍)}
    </thead>
    <tbody style={{ height: `${virtualizer.getTotalSize()}px`, position: 'relative' }}>
      {virtualizer.getVirtualItems().map(virtualRow => (
        <tr
          key={row.id}
          style={{ position: 'absolute', top: `${virtualRow.start}px`, height: `${virtualRow.size}px`, width: '100%' }}
          data-selected={row.original.nhtsaId === selectedCommId}
          onClick={() => onRowClick(row.original)}
        >
          {row cells}
        </tr>
      ))}
    </tbody>
  </table>
</div>
```

**Loading state:** Render 8 skeleton rows matching the column layout.

**Empty state:** Render a centered message "No communications match your filters" with a suggestion to clear filters.

Create `frontend/src/components/composite/FilterChips.tsx`:

```tsx
import { X } from 'lucide-react';
import type { CommType } from '@/client';
import { COMM_TYPE_COLORS, COMM_TYPE_LABELS } from '@/client';
import styles from './FilterChips.module.css';

interface FilterChipsProps {
  searchTerm: string;
  selectedTypes: CommType[];
  onClearSearch: () => void;
  onRemoveType: (type: CommType) => void;
  onClearAll: () => void;
}

export function FilterChips({
  searchTerm,
  selectedTypes,
  onClearSearch,
  onRemoveType,
  onClearAll,
}: FilterChipsProps) {
  const hasFilters = searchTerm.trim().length > 0 || selectedTypes.length > 0;
  if (!hasFilters) return null;

  const totalFilters = (searchTerm.trim() ? 1 : 0) + selectedTypes.length;

  return (
    <div className={styles.chipBar}>
      {searchTerm.trim() && (
        <button className={styles.chip} onClick={onClearSearch}>
          <span className={styles.chipLabel}>Search: "{searchTerm}"</span>
          <X size={12} className={styles.chipClose} />
        </button>
      )}
      {selectedTypes.map((type) => (
        <button
          key={type}
          className={styles.chip}
          style={{ '--chip-color': COMM_TYPE_COLORS[type] } as React.CSSProperties}
          onClick={() => onRemoveType(type)}
        >
          <span
            className={styles.chipDot}
            style={{ backgroundColor: COMM_TYPE_COLORS[type] }}
          />
          <span className={styles.chipLabel}>{COMM_TYPE_LABELS[type] || type}</span>
          <X size={12} className={styles.chipClose} />
        </button>
      ))}
      {totalFilters >= 2 && (
        <button className={styles.clearAll} onClick={onClearAll}>
          Clear all
        </button>
      )}
    </div>
  );
}
```
